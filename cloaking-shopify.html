Alternative Method

Shopify Redirect

Use a Shopify store as your redirect page

This script is added to your Shopify store. When someone clicks your TikTok ad, they land on your Shopify homepage and get automatically redirected to your main landing page.

The script only redirects mobile users with a valid TikTok click ID (ttclid starting with E_C_P). This ensures only real TikTok ad clicks are redirected.

Setup

  1. Go to your Shopify admin → Online Store → Themes
  2. Click Edit code
  3. Open the theme.liquid file
  4. Find the line <!doctype html>
  5. Paste the script on the second line, right after <!doctype html>
  6. Repeat for the password.liquid file
  7. Click Save

The Script

Copy and paste this script. Change https://main-lander.com to your actual landing page URL:

script-shopify-redirect.html 
<script>
(function() {
    function getURLParameter(name) {
        const urlParams = new URLSearchParams(window.location.search);
        return urlParams.get(name);
    }

    (function ensureTTCLIDParamOnLander() {
        try {
            const u = new URL(window.location.href);
            if (!u.searchParams.has('ttclid')) {
                u.searchParams.set('ttclid', '');
                history.replaceState(null, '', u.toString());
            }
        } catch(e) {}
    })();

    const ttclid = getURLParameter('ttclid') || '';
    const isMobile = window.innerWidth <= 768 || /Mobi|Android|iPhone|iPad|iPod/i.test(navigator.userAgent);

    if (isMobile) {
        if (!ttclid || !ttclid.startsWith('E_C_P')) {
            return;
        }

        const campaignUrl = 'https://main-lander.com';

        const finalURL = new URL(campaignUrl);
        const currentParams = new URLSearchParams(window.location.search);

        currentParams.forEach((value, key) => {
            finalURL.searchParams.set(key, value);
        });

        finalURL.searchParams.set('ttclid', ttclid);

        window.location.href = finalURL.toString();
    }
})();
</script>

Reminder: Copy and paste this script. Change https://main-lander.com to your actual landing page URL before saving.
